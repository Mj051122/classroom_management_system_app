# Panthraa App Plans

This folder stores focused development context for Panthraa. Start here, then open only the file related to the feature you are changing.

## Files

- `architecture-map.md` - app structure, ownership, key files.
- `data-cache-refresh.md` - cache policy, read guard, pull-to-refresh flow.
- `assignments-submissions.md` - professor uploads, student required file submissions.
- `supabase-database.md` - live database expectations, RPCs, storage buckets.
- `ui-screens.md` - major Compose screens, dashboard schedule UX, navigation/back behavior, and refresh rules.
- `design-audit-workflow.md` - whole-app UI/UX audit workflow using ui-ux-pro-max, impeccable, and grill-me.
- `testing-release.md` - build/test commands and manual QA.
- `open-risks.md` - known risks to protect during future work.

## Update Rule

When a feature changes, update the matching file in this folder during the same turn. Keep each file short and durable.
