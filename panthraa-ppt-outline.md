# Panthraa PPT Outline

## Introduction

Panthraa is a student and professor management system designed to make class activities easier to organize. It helps users manage classes, assignments, attendance, grades, schedules, and announcements in one application.

The system supports both student and professor accounts, allowing each user to access the features they need based on their role.

## Objectives

- To provide an easy-to-use platform for students and professors.
- To organize class information in one system.
- To help professors manage assignments, attendance, and grades.
- To help students view classes, tasks, schedules, and grades.
- To reduce manual work and improve communication between users.

## Scope Of The System

The system includes the following features:

- User login and profile management.
- Student and professor dashboards.
- Class creation and class joining.
- Assignment posting and submission.
- Attendance monitoring.
- Grade monitoring and export.
- Schedule viewing through the app and widget.
- Announcements and task reminders.
- Offline support for saved data.

The system focuses on academic class management and does not include full school administration features such as enrollment payment, registrar processing, or accounting.

## System Flow

1. The user logs in to the application.
2. The system identifies the user as a student or professor.
3. Students can view classes, assignments, schedules, grades, and announcements.
4. Professors can create classes, post assignments, record attendance, monitor grades, and manage students.
5. The system saves and updates data through the online database.
6. If offline, the system shows the last saved data until internet connection is available.

## Emerging Technologies

Panthraa uses modern technologies to improve performance, usability, and reliability:

- Mobile application development for convenient access.
- Cloud database for real-time data storage and retrieval.
- Offline caching so users can still view saved information without internet.
- QR-based attendance support for faster checking.
- Home screen widget for quick schedule viewing.
- Data export for easier grade reporting.

## Conclusion

Panthraa helps simplify class management for both students and professors. It improves organization, communication, and access to academic information through one mobile application.
