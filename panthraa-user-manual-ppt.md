## Slide 2: Introduction

Panthraa is a mobile application that helps students and professors manage class activities in one place.

The app allows users to view classes, assignments, grades, schedules, announcements, and attendance records.

**Screenshot to insert:** Main dashboard screen or app home screen.

## Slide 3: Getting Started

1. Open the Panthraa app.
2. Log in using your registered account.
3. The system will identify if you are a student or professor.
4. After login, you will be directed to your dashboard.

**Screenshot to insert:** Login screen and dashboard after login.

## Slide 4: Main Navigation

The app has three main navigation tabs:

- **Dashboard** - shows an overview of important updates.
- **Classes** - displays joined or created classes.
- **Announcements** - shows class news and updates.

The navigation bar hides when scrolling down and appears again when scrolling up.

**Screenshot to insert:** Bottom navigation bar showing Dashboard, Classes, and Announcements.

## Slide 5: Student Dashboard

Students can use the dashboard to quickly view:

- Current subjects.
- Pending tasks.
- Grades overview.
- Schedule updates.
- Class announcements.

## Slide 6: Student Classes

In the Classes page, students can:

- View enrolled classes.
- Open class details.
- Check assignments and materials.
- Submit required tasks.
- View classmates and class information.

## Slide 7: Student Assignments

Students can submit assignments by:

1. Opening a class.
2. Selecting an assignment.
3. Reading the instructions.
4. Attaching the required file if needed.
5. Tapping submit.

Submitted tasks can show scores once graded by the professor.

- View their overall grade.

- Check recorded scores from assignments.

## Slide 12: Creating A Class

To create a class:

1. Go to the Classes page.
2. Tap create class.
3. Enter class information.
4. Save the class.
5. Students can join the class once it is available.

**Screenshot to insert:** Create Class form screen.

## Slide 13: Posting Assignments

Professors can post assignments by:

1. Opening a class.
2. Selecting upload or create assignment.
3. Adding title, instructions, category, points, and deadline.
4. Uploading a file if needed.
5. Saving the assignment.

## Slide 17: Offline Support

Panthraa can show saved data even without internet connection.

When offline, users can still view previously loaded:

- Classes.
- Assignments.
- Grades.
- Announcements.
- Schedules.

Online connection is needed to submit, update, or refresh data.

**Screenshot to insert:** Offline message or cached data screen.

## Slide 18: Common Tips

- Refresh the page if data does not update.
- Make sure internet is available before submitting assignments.
- Check deadlines regularly.
- Use the schedule widget for quick class reminders.
- Contact the professor if a grade or task is missing.

**Screenshot to insert:** Any useful app screen showing refresh, deadline, or widget feature.

## Slide 19: Troubleshooting

If the app has a problem:

- Check your internet connection.
- Close and reopen the app.
- Refresh the current page.
- Make sure you are logged in with the correct account.
- Report the issue if the problem continues.

**Screenshot to insert:** Error message, offline notice, or refresh screen.
